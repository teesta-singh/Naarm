# Naarm Visit

A family trip planner for Melbourne (Naarm), 14 Dec 2026 – 4 Jan 2027. Public transport only, mostly free days.

Follow along on Instagram: [@ohlyans_at_naarm](https://instagram.com/ohlyans_at_naarm)

## Update the site
Upload every file in this folder to the repo root, replacing the old ones, then commit. GitHub Pages refreshes within a minute or two.

## Add to your phone's home screen
- **iPhone (Safari):** Share → *Add to Home Screen*
- **Android (Chrome):** ⋮ → *Install app*

## Notes
- Edits, checklist ticks and photos are saved on each phone only.
- Set your home address in ☰ → Settings. It's stored on that phone and never published.
