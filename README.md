# Naarm Visit

A family trip planner for Melbourne (Naarm). It works on public transport only, and most of the days are free.

**Open it:** `https://<your-username>.github.io/naarm-visit/`

## Add to your phone's home screen
- **iPhone (Safari):** tap Share, then *Add to Home Screen*.
- **Android (Chrome):** tap ⋮, then *Add to Home screen* or *Install app*.

## Notes
- Each phone keeps its own plan edits, checklist ticks and photos. Nothing syncs between phones.
- Set your home address in **Dates**. It's stored only on that phone, so the address is never published.
- Fares and timetables change, so check the PTV app the day before.
